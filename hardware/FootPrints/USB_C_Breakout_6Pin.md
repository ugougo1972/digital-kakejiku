## 2. 目的

本書は、DigitalKakejiku電源基板で使用するUSB Type-Cブレークアウトモジュールについて、KiCadフットプリントの設計根拠、実測寸法、レイヤー構成、Pad仕様、機械寸法および検証条件を管理するための基準文書である。

本フットプリントは市販モジュールのメーカー公称値ではなく、使用予定現物の実測値を優先して作成する。

---

## 3. 適用範囲

本書の適用対象は次のとおり。

- USB Type-Cコネクタ実装済み6Pinブレークアウトモジュール
- 2.54mmピッチのスルーホール端子列
- 2個の固定穴を持つモジュール基板
- DigitalKakejiku電源基板への実装
- KiCadプロジェクト専用ライブラリ `PowerModules.pretty`

本書はUSB Type-Cコネクタ単体のフットプリント仕様ではない。

現物2個の測定結果は次のとおり。

| 測定対象 | 実測値 |

実測値9.01mmに対し、公差を考慮して設計値9.00mmを採択する。

## 7. Pad仕様

### 7.1 共通仕様

| 項目 | 設計値 |
|---|---|
| 種別 | スルーホールPad |
| 形状 | 円形を基本とする |
| Padサイズ | φ1.80mm |
| ドリル径 | φ1.00mm |
| メッキ | 有り |
| ピッチ | 2.54mm |
| レイヤー | `*.Cu` / `*.Mask` |
| 原点 | Pad 1中心 |

### 7.2 Pad 1識別

Pad 1は以下の方法で他Padと識別可能にする。

- Pad 1形状を角丸四角形または矩形とする
- F.SilkS上にPin 1マーカーを配置する
- F.Fab上にもPin 1識別を設ける

Pad 1の外径相当は、他Padと同じ1.80mmを基本とする。

### 7.3 Pad番号と信号

フットプリントではPad番号のみを定義する。信号名は回路図シンボル側で割り当てる。

現物基板の端子表示順として確認済みの信号配列は次のとおり。

| 現物表示順 | 信号 |
|---:|---|
| 1 | VBUS |
| 2 | GND |
| 3 | CC1 |
| 4 | D- |
| 5 | D+ |
| 6 | CC2 |

ただし、KiCad上のPad 1からPad 6までの物理方向は、実装面視点の写真または現物照合により座標確定時に再確認する。

## 8. 固定穴仕様

| 項目 | 設計値 |
|---|---|
| 数量 | 2 |
| 穴径 | φ3.30mm |
| 穴間距離 | 16.50mm |
| Pad種別 | NPTH機械穴を基本とする |
| 銅箔 | 原則なし |
| はんだマスク | 穴周囲開口 |
| 番号 | 付与しない |

固定穴が現物で銅メッキされている場合でも、電気接続を目的としない限りKiCad上ではNPTHとして扱う。

固定穴中心の絶対座標は、Pad 1からのX・Yオフセット実測後に確定する。

## 9. レイヤー別設計仕様

### 9.1 F.Fab

F.Fabには次の実外形を記載する。

- モジュール基板外形：21.60mm × 14.20mm
- USB金属シェル外形：幅9.00mm、奥行7.40mm
- USBコネクタの基板端からの突出：1.40mm
- 固定穴中心位置
- Pin 1識別
- 必要に応じて端子列中心線

線幅は0.10mmを基本とする。

基板外形、端子列およびUSBコネクタの位置関係は、Pad 1基準の実測座標で確定する。

### 9.2 F.SilkS

F.SilkSには次の情報を配置する。

- 部品識別名または短縮名
- Pin 1マーカー
- 実装方向が判別できる最小限の外形線

推奨表示名：

```text
USB-C 6P
```

シルク線はPad、固定穴およびはんだマスク開口に重ならないこと。

シルク線幅は0.15mmを基本とする。

### 9.3 F.Courtyard

F.Courtyardは、実装後に占有する最大外形から全方向へ0.50mm拡張する。

対象外形には次を含む。

- モジュール基板
- USB金属シェル
- 基板端から突出するUSBコネクタ部分

単に21.60mm × 14.20mmの基板外形だけを拡張するのではなく、1.40mmのUSB突出部を含む最大外形を基準とする。

Courtyard線幅は0.05mmを基本とする。

### 9.4 F.CrtYd形状

USB突出方向を含めた外接矩形を基本とする。

複雑な段差形状を採用する場合は、実装禁止領域が過小にならないことを優先する。

## 12. 次工程で作成する座標表

座標仕様書では次の順に絶対座標を確定する。

1. Pad 1～Pad 6
2. モジュール基板外形（F.Fab）
3. 固定穴2個
4. USB金属シェル外形（F.Fab）
5. F.Courtyard
6. F.SilkS
7. ReferenceおよびValue配置

座標表は以下の形式を使用する。

```text
要素 / レイヤー / 始点X / 始点Y / 終点X / 終点Y / 寸法 / 備考
```

Padおよび固定穴は以下の形式を使用する。

```text
番号 / 種別 / X / Y / Pad径 / 穴径 / 形状 / 備考
```

## 15. 判定基準

| 判定 | 条件 |
|---|---|
| PASS | 全実測寸法、Pad番号、固定穴、外形、Courtyardおよび実装方向が一致 |
| FAIL | いずれかの寸法不一致、Pad方向逆転、固定穴不一致、USB突出部の未反映 |
| HOLD | Pad 1基準オフセットなど、座標確定に必要な実測値が不足 |

現時点の判定は以下とする。

```text
HOLD
```

理由：Pad 1を基準とした基板外形、固定穴およびUSBシェルの絶対座標が未確定であるため。
