# 1. 目的

本書は、DigitalKakejikuプロジェクトで使用する KiCad フットプリントライブラリ
`PowerModules.pretty`
の設計規約を定義する。

本規約の目的は以下のとおりである。

- ライブラリ品質の統一
- 再利用性の向上
- レビュー容易性の向上
- GitHub上での長期管理
- 実測値に基づく高信頼設計

本規約は PowerModules ライブラリに登録する全フットプリントへ適用する。

---

# 2. 適用範囲

本規約は以下に適用する。

- USBモジュール
- 電源モジュール
- センサーモジュール
- XIAOシリーズ
- RTCモジュール
- 表示モジュール
- その他 PowerModules.pretty に登録する全フットプリント

対象外

- 回路図シンボル
- PCB設計ルール
- 配線設計

---

# 3. 設計思想

PowerModulesライブラリは、

**「現物を正確に再現する機械部品ライブラリ」**

として設計する。

設計において優先順位は以下とする。

1. 現物実測値
2. 実装確認結果
3. メーカー図面
4. データシート
5. 推測（禁止）

---

# 4. 基本方針

## 4.1 原点

すべてのフットプリントは

**基板中心**

を原点とする。

```
        Y(-)

──────────────
      ●
    Origin
──────────────

        Y(+)
```

X方向

- 左：負
- 右：正

Y方向

- 上：負
- 下：正

---

## 4.2 単位

すべて

```
mm
```

とする。

座標は

```
0.01mm
```

単位で管理する。

---

## 4.3 実測優先

寸法は

```
現物実測
```

を採択する。

メーカー寸法との差異がある場合は

現物を優先する。

---

## 4.4 推測禁止

未確認事項は

```
未確認
```

と記載する。

設計者の推測による補完は禁止する。

---

# 5. Pad規約

## 5.1 Pad番号

Pad番号は

```
1～n
```

の連番とする。

例

```
1
2
3
4
```

---

## 5.2 信号名

Padには

```
VBUS
GND
...
```

などの信号名を持たせない。

信号名は

回路図シンボル側で管理する。

---

## 5.3 Pad形状

Pad1

```
角丸長方形
```

または

```
矩形
```

Pad2以降

```
円形
```

を基本とする。

---

# 6. レイヤー規約

|対象|Layer|
|---|---|
|基板外形|F.Fab|
|主要機械外形|F.Fab|
|Pad|Through Hole|
|固定穴|NPTH Mechanical|
|Pin1マーク|F.SilkS|
|部品名称|F.SilkS|
|端子名称|F.SilkS|
|Reference|F.SilkS(Field)|
|Value|F.Fab(Field)|
|Courtyard|F.Courtyard|

---

# 7. F.Fab

F.Fabには

- 基板外形
- コネクタ外形
- 機械部品外形

を実寸で描画する。

線幅

```
0.10mm
```

を推奨する。

---

# 8. F.SilkS

表示する情報

- 部品名称
- Pin1
- 端子名称（配置可能な場合）
- Reference

線幅

```
0.15mm
```

推奨。

Padとは重ねない。

---

# 9. F.Courtyard

最大機械外形を基準とする。

四方向へ

```
0.50mm
```

拡張する。

USBコネクタ等、

基板から突出する部品は

必ず含める。

---

# 10. Description

Descriptionには

以下を記載する。

- 部品種別
- 外形寸法
- Pin数
- Pitch
- 実測採用

---

# 11. Keywords

検索性向上のため、

一般名称を含める。

例

```
USB-C
Type-C
Breakout
6Pin
Power
```

---

---

# 13. 品質基準

レビュー結果は

|判定|意味|
|---|---|
|PASS|登録可能|
|FAIL|修正必須|
|HOLD|未確認事項あり|

---

# 14. 保存確認

ライブラリ登録後は必ず

1. 保存
2. エディタ終了
3. ライブラリ再読込

を実施する。

再読込できない場合は

登録完了としない。
