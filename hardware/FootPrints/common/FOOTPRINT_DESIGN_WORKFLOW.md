# 1. 目的

本書は PowerModules.pretty に新規フットプリントを登録する際の標準作業手順（SOP）を定義する。

本手順に従うことで、すべてのフットプリントを同一品質で作成・レビュー・登録することを目的とする。

---

# 2. 適用範囲

本書は以下のすべてに適用する。

- USBモジュール
- 電源モジュール
- センサーモジュール
- MCUモジュール
- RTCモジュール
- Displayモジュール
- その他 PowerModules.pretty に登録する全フットプリント

---

# 3. 役割分担

|担当|役割|
|---|---|
|設計者|現物測定・設計・KiCad入力・最終判断|
|PCB設計レビュー担当|仕様整理・レビュー・整合性確認・改善提案|

---

# 4. 設計フロー

```
現物入手
      │
      ▼
現物実測
      │
      ▼
設計値採択
      │
      ▼
仕様書作成
      │
      ▼
座標仕様書作成
      │
      ▼
KiCad入力
      │
      ▼
設計レビュー
      │
      ▼
修正
      │
      ▼
保存
      │
      ▼
ライブラリ再読込
      │
      ▼
PCB配置確認
      │
      ▼
GitHub登録
```

---

# 5. 現物実測

設計値は以下の優先順位で採択する。

1. 現物実測
2. メーカー図面
3. データシート

推測は禁止する。

未確認項目は

```
未確認
```

と記載する。

---

# 6. 座標決定

原点は

```
基板中心
```

とする。

例外を設けない。

座標精度

```
0.01mm
```

---

# 7. KiCad入力順

以下の順番を厳守する。

1. F.Fab
2. Pad
3. 固定穴（NPTH）
4. 機械外形
5. Reference
6. Value
7. Pin1マーク
8. 部品名称
9. 端子名称
10. F.Courtyard

---

# 8. レイヤー確認

|Layer|内容|
|---|---|
|F.Fab|基板・機械外形|
|F.SilkS|Pin1・部品名・端子名・Reference|
|F.Courtyard|最大外形+0.5mm|

---

# 9. フィールド設定

Reference

- KiCadフィールド
- 通常テキスト禁止

Value

- フットプリント名

Description

- 部品説明
- 寸法
- 実測採用

Keywords

- 検索性重視

---

# 10. 保存確認

保存後は以下を必ず実施する。

1. 保存
2. エディタ終了
3. ライブラリ再読込

再読込できない場合は登録完了としない。

---

# 11. PCB確認

テストPCBへ配置し、以下を確認する。

- Pad番号
- Pad位置
- 固定穴
- Courtyard
- DRC
- 実装方向

---

# 12. GitHub登録

登録対象

- 仕様書
- 座標仕様書
- ChangeLog
- レビュー結果

---

# 13. 完了条件

以下をすべて満たした場合のみ正式登録とする。

- 設計レビュー PASS
- 保存確認 PASS
- ライブラリ再読込 PASS
- PCB確認 PASS
- GitHub更新完了

---

# 14. 設計判断の記録

フットプリントごとに以下を記録する。

- 原点採用理由
- 寸法採択理由
- 特殊な設計判断
- 採用しなかった案
- レビュー指摘事項

この情報は仕様書の「Design Rationale」に記載する。
