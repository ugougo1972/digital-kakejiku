## 3. 座標確定に必要な実測値

以下の値を、Pad 1中心基準で実測する。

| 記号 | 実測項目 | 値 |
|---|---|---:|
| `L` | Pad 1中心から基板左端まで | 未測定 |
| `R` | Pad 1中心から基板右端まで | 未測定 |
| `T` | Pad 1中心から基板上端まで | 未測定 |
| `B` | Pad 1中心から基板下端まで | 未測定 |
| `HX1` | 固定穴1中心のX座標 | 未測定 |
| `HY1` | 固定穴1中心のY座標 | 未測定 |
| `HX2` | 固定穴2中心のX座標 | 未測定 |
| `HY2` | 固定穴2中心のY座標 | 未測定 |
| `SX1` | USBシェル左端X座標 | 未測定 |
| `SX2` | USBシェル右端X座標 | 未測定 |
| `SY1` | USBシェル上端Y座標 | 未測定 |
| `SY2` | USBシェル下端Y座標 | 未測定 |

整合条件：

```text
L + R = 21.60
T + B = 14.20
|HX2 - HX1| または |HY2 - HY1| = 16.50
|SX2 - SX1| = 9.00
|SY2 - SY1| = 7.40
```

固定穴が斜め配置の場合は、次式で確認する。

```text
sqrt((HX2 - HX1)^2 + (HY2 - HY1)^2) = 16.50
```
