# digital-kakejiku PowerBoard Rev.0

## 1. 位置付け

本データは、digital-kakejiku 電源基板PoCの実測結果と、以下の確定済み構成を基に作成した
**KiCad 10取込用の初期設計データ**です。

```text
USB Type-C
    │
   PTC
    │
  IP5306
    │
DMG2305UX-13
    │
  5V_BUS
    │
 TPS63802
    │
 3.3V_OUT
```

## 2. 重要な注意

本データは **JLCPCBへそのまま発注できる最終製造版ではありません**。

理由は、実際に使用する以下の市販モジュールについて、外形寸法・端子ピッチ・穴径が
リポジトリ文書だけでは確定できないためです。

- USB Type-Cブレークアウト基板
- IP5306モジュール
- TPS63802モジュール
- 18650接続コネクタ
- 本体基板接続用10ピンヘッダーの実装形態

現在のPCBデータでは、これらを汎用2.54 mmピッチのスルーホール部品として仮配置しています。
実物を採寸し、フットプリントを確定してから製造データを生成してください。

|ファイル|用途|

## 4. KiCad 10での開始手順

1. ZIPを展開します。
2. KiCad 10を起動します。
3. `PowerBoard_Rev0.sch`を回路図エディターで開きます。
4. 変換確認が表示された場合は、KiCad 10形式で保存します。
5. 保存名を `PowerBoard_Rev0.kicad_sch` とします。
6. `PowerBoard_Rev0.kicad_pcb`をPCBエディターで開きます。
7. フットプリント実寸を確認・修正します。
8. 回路図からPCBを更新します。
9. ERC・DRCを実行します。
10. エラーおよび未確認警告が残る状態ではJLCPCBへ発注しません。

## 6. GND方針

- 5V_GND、3.3V_GND、SENSE_GNDは電源基板上で意図的に別ネットとしています。
- 本体基板側のXIAO近傍で一点接続する設計方針です。
- これは電気的絶縁ではなく、リターン経路整理によるノイズ低減を目的とします。
- 使用モジュール内部でGNDが導通している可能性は、実物の導通測定で確認してください。

## 9. 製造禁止条件

以下のいずれかに該当する場合、Gerber発注を行わないでください。

- 実物採寸が未完了
- モジュールの端子順が未確認
- MOSFETのS/G/D対応が未確認
- ERCまたはDRCに未解決エラーがある
- 3系統GNDの意図と実モジュール内部導通が未評価
- 1:1印刷による部品実装確認が未実施
