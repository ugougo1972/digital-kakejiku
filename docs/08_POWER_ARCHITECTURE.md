# 1. 目的

本書は digital-kakejiku における電源アーキテクチャの基準源である。

本書では、電源基板の構成、設計思想、配線方針、実装方針および運用方針を定義する。

詳細な配線座標および端子番号は
「05_WIRING_DIAGRAM.md」を基準源とし、
本書では設計思想および構成を中心に記載する。

---

# 2. 基本設計方針

本プロジェクトでは、USB給電を通常動作とし、
停電時のみ18650リチウムイオン電池へ自動切り替えを行う
UPS方式を採用する。

電源切替はIP5306およびDMG2305UX-13によるハードウェア構成で実現し、
ESP32は電源経路の切替を制御しない。

PowerManagerは電源状態の監視およびログ管理のみを担当する。

# 4. USB-C方針

USB-Cコネクタは

- 外部5V入力
- USB通信

の2用途を兼ねる。

採用するUSB-C基板には

- CC1：5.1kΩ
- CC2：5.1kΩ

が実装済みである。

したがって、

**外付けCC抵抗は実装しない。**

USB通信線（D+・D-）は電源系とは独立して扱い、
本体基板上のXIAO ESP32S3 Plusへ接続する。

---

# 5. 電源ブロック

電源構成は以下の通りとする。

```text
USB-C
    │
    ▼
PTC（Polyfuse）
    │
    ▼
IP5306
 ├────18650 Battery
 │
 └────OUT_5V
          │
          ▼
   DMG2305UX-13
          │
          ▼
      5V_OUT
      ├────────────5V_OUT
      ├────────────5V_SENSE
      └────TPS63802 VIN
                    │
                    ▼
              TPS63802
                    │
                    ▼
               3.3V_OUT
                    │
       ├────────3.3V_OUT
       └────────3.3V_GND
```

本構成では、

- USB給電を優先する。
- 停電時はIP5306により18650給電へ切り替える。
- DMG2305UX-13は5V_OUTへの逆流抑制および電源経路保護を目的として使用する。
- TPS63802は5V_OUTから3.3V_OUTを生成する。

電源基板は本体基板とは独立したサブ基板とし、
本体基板とは10PINインターフェースを介して接続する。

四隅のヘッダーピンは電気接続には使用せず、
支柱固定専用とする。

# 6. PowerManager

PowerManagerは電源経路の切替を制御しない。

本システムでは、USB給電と18650給電の切替はIP5306および
DMG2305UX-13によるハードウェアで自律的に行う。

PowerManagerは現在の電源状態を監視し、
システム全体へ通知する責務のみを持つ。

## 責務

- USB給電状態の監視
- バッテリー電圧の監視
- 電源モードの判定
- event_logへの記録
- system_logへの記録
- 異常時のerror_log出力

PowerManagerはMOSFET、IP5306、TPS63802等の
制御信号を直接操作しない。

---

## 電源モード

| モード | 説明 |
|---------|------|
| USB_MODE | USB給電中 |
| BATTERY_MODE | 停電により18650から給電中 |

USB_MODEとBATTERY_MODEは
5V_SENSEおよびBattery_SENSEから判定する。

---

## 停電時の優先順位

停電発生時は以下の優先順位で動作する。

1. RTC維持
2. ESP32継続動作
3. センサー観測継続
4. microSD保存
5. 通信頻度抑制
6. E-Paper更新抑制

PowerManagerはこれらの状態遷移を通知するのみであり、
実際の制御は各Subsystemが行う。

---

# 7. 電源基板構成

電源基板は独立したサブ基板として構成する。

本体基板とは10PINコネクタで接続し、
電源生成・電圧監視機能を集約する。

## 構成ブロック

| ブロック | 機能 |
|-----------|------|
| USB-C | 外部5V入力・USB通信 |
| PTC | 過電流保護 |
| IP5306 | 充電・昇圧・電源切替 |
| DMG2305UX-13 | 5V経路保護・逆流抑制 |
| TPS63802 | 3.3V生成 |
| Battery_SENSE | 電池電圧監視 |
| 5V_SENSE | USB給電監視 |

---

## 10PINインターフェース

電源基板と本体基板は
10PINコネクタで接続する。

役割は以下の通りとする。

| 系統 | 用途 |
|------|------|
| 5V_OUT | 配電専用 |
| 5V_GND | 配電専用 |
| 3.3V_OUT | 配電専用 |
| 3.3V_GND | 配電専用 |
| Battery_SENSE | 測定専用 |
| 5V_SENSE | 測定専用 |
| SENSE_GND | 測定専用 |

Battery_SENSE、
5V_SENSE、
SENSE_GNDは
測定専用とし、
他用途への流用は禁止する。

# 8. GND設計

## 基本方針

本設計では、
TPS63802内部でGNDが共通であっても、
基板設計上はこれを考慮しない。

設計上は

- 5V_GND
- 3.3V_GND
- SENSE_GND

の3系統を
独立したリターン経路として扱う。

目的は電位分離ではなく、

**大電流経路と測定基準経路を分離することによる
ノイズ低減**

である。

---

## 配線方針

電源基板上では

5V_GND

3.3V_GND

SENSE_GND

を途中で接続しない。

各GNDは
10PINコネクタまで
独立した配線で引き出す。

---

## 一点接続

各GNDは
電源基板では接続しない。

本体基板側において

XIAO ESP32S3 Plus近傍

をシステムGND基準点とし、

一点接続する。

これ以外の位置で
GND同士を接続してはならない。

---

## TPS63802との関係

TPS63802モジュール内部では

VIN_GND

VOUT_GND

が導通している可能性がある。

しかし、

本設計ではこれを設計上無視する。

設計思想としては

- 5V_GND
- 3.3V_GND
- SENSE_GND

を完全分離して配線する。

---

## 配線上の注意

- 5V_GNDにはUSB入力電流および負荷電流が流れる。
- 3.3V_GNDにはTPS63802出力系のみを接続する。
- SENSE_GNDには分圧回路以外を接続しない。
- SENSE_GNDへ大電流を流してはならない。
- GNDを途中でジャンパ接続してはならない。

以上を電源基板の設計基準とする。

---

電源基板ではUSB電源と通信系を独立して扱う。

- CC2：5.1kΩ

そのため、

**外付けCC抵抗は実装しない。**

二重実装は禁止する。

# 10. IP5306

## 役割

IP5306は

- リチウムイオン電池充電
- 昇圧
- UPS切替

を担当する。

PowerManagerから制御は行わない。

---

## 接続

| 端子 | 接続先 |
|------|--------|
| VIN | PTC出力 |
| BAT | 18650 |
| GND | 5V_GND |
| OUT_5V | DMG2305UX-13 Source |

---

## BAT端子

BAT端子から

Battery_SENSE

を取り出す。

100kΩ

100kΩ

本体基板へ出力する。

# 11. DMG2305UX-13

## 役割

DMG2305UX-13は

5V経路保護

および

逆流抑制

を目的として使用する。

本構成は

理想ダイオードIC

ではない。

そのため、

完全な逆流防止回路ではない。

---

## 接続

正式接続は以下とする。

| 端子 | 接続 |
|------|------|
| Source | IP5306 OUT_5V |
| Drain | 5V_OUT |
| Gate | 100kΩ→5V_GND |

Drain、

Source

の逆接続は禁止する。

---

## Gate

Gateは

100kΩ

で

5V_GND

へ接続する。

PowerManagerによる
GPIO制御は行わない。

---

## 制約

以下は禁止する。

- 5V_OUTへの外部5V注入
- XIAO USB VBUSからの逆給電
- DMG2305UX-13をリレー代わりに使用すること

## GND

GNDは

3.3V_GND

設計上は

5V_GND

独立して扱う。

TPS63802内部で導通していても

## 入力コンデンサ

# 13. コンデンサ構成

## 基本方針

コンデンサは

- 高周波ノイズ除去
- 電源安定化
- 瞬時電流供給

を目的として配置する。

容量を過度に増やすのではなく、

**小容量コンデンサとバルクコンデンサを役割分担させる**

ことを基本設計とする。

---

## USB入力

USB入力（PTC後段）には

| 容量 | 用途 |
|------|------|
| 0.1µF | 高周波ノイズ除去 |
| 470µF | バルクコンデンサ |

を配置する。

0.1µFはIP5306 VIN直近、

470µFはその外側へ配置する。

---

## TPS63802入力

TPS63802 VINには

| 容量 | 用途 |
|------|------|
| 0.1µF | 高周波除去 |
| 470µF | バルクコンデンサ |

を配置する。

配置順序は

TPS63802

↓

0.1µF

↓

470µF

とする。

---

## TPS63802出力

TPS63802 VOUTには

| 容量 | 用途 |
|------|------|
| 0.1µF | 高周波除去 |
| 220µF | バルクコンデンサ |

を配置する。

配置順序は

TPS63802

↓

0.1µF

↓

220µF

とする。

220µFは

3.3V系負荷変動を吸収することを目的とする。

---

## コンデンサ配置方針

コンデンサは

電源ICへ近い順に

- 0.1µF
- バルクコンデンサ

の順で配置する。

配線は最短とし、

GND側も最短で戻す。

---

↓

5V_SENSE

↓

100kΩ

0.1µF

の下側抵抗および

SENSE_GNDへ

# 17. テストポイント

## 基本方針

電源基板はPoCおよび保守性を考慮し、
主要な測定箇所へテストポイントを設ける。

通常の電圧測定用テストポイントは
1PINヘッダーまたはランドとする。

GND測定用には
ワニ口クリップを接続できるGNDループを
少なくとも1箇所設ける。

USB D+、D-は
通信品質を優先し、
テスト用ヘッダーは設けない。

---

# 18. 通電前チェック

## 導通確認

初回通電前に
以下を必ず確認する。

| 項目 | 判定 |
|------|------|
| USB VBUS－5V_GND短絡なし | □ |
| PTC出力－5V_GND短絡なし | □ |
| 5V_OUT－5V_GND短絡なし | □ |
| TPS63802 VIN－5V_GND短絡なし | □ |
| TPS63802 VOUT－3.3V_GND短絡なし | □ |
| 5V_OUT－3.3V_OUT短絡なし | □ |

---

## GND確認

以下を確認する。

- 5V_GNDが独立していること
- 3.3V_GNDが独立していること
- SENSE_GNDが独立していること
- 電源基板上でGND同士を接続していないこと

TPS63802内部導通は
設計対象外とする。

---

## SENSE確認

以下を確認する。

- Battery_SENSE分圧中点
- 5V_SENSE分圧中点
- 下側抵抗がSENSE_GNDへ接続されていること
- 0.1µFが正しく接続されていること

---

## DMG2305UX-13確認

初回通電前に

| 端子 | 接続 |
|------|------|
| Source | OUT_5V |
| Drain | 5V_OUT |
| Gate | 100kΩ→5V_GND |

であることを確認する。

SourceとDrainの逆接続は禁止する。

---

## TPS63802確認

以下を確認する。

- VIN外側ホールが主配線であること
- VIN内側ホールがコンデンサ接続であること
- VOUT外側ホールが主配線であること
- VOUT内側ホールがコンデンサ接続であること
- 0.1µFがIC直近に配置されていること
- 470µFおよび220µFが外側に配置されていること

---

## 初回通電

初回通電は

1. USB入力のみ
2. 無負荷
3. 5V_OUT確認
4. TPS63802入力確認
5. 3.3V出力確認

の順で実施する。

その後、

XIAO ESP32S3 Plusのみを接続し、
起動確認を行う。
