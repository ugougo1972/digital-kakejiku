# 1. 本書の目的

## 1.1 目的

本書は digital-kakejiku の配線設計に関する基準文書である。

本書では以下を定義する。

- システム全体配線
- 電源配線
- 信号配線
- バス構成
- 本体基板・電源基板間インターフェース
- 配線設計ルール
- 通電試験手順

部品仕様および設計思想については **08_POWER_ARCHITECTURE.md** を、ハードウェア全体構成については **01_HARDWARE_OVERVIEW.md** を基準とする。

---

## 1.2 配線設計方針

本システムでは以下を設計原則とする。

- 電源系と通信系を分離する。
- 配線交差を最小限とする。
- GNDリターンを明確化する。
- 保守・交換を考慮し、モジュール単位で配線する。
- 本体基板・電源基板・OLED操作基板の3基板構成を前提とする。

# 3. 電源配線

## 3.1 電源ブロック

```text
USB Type-C
      │
      ▼
PTC
      │
      ▼
IP5306
      │
      ▼
DMG2305UX-13
      │
      ▼
5V_BUS
 ├─────────────5V_OUT
 ├─────────────5V_SENSE
 └─────────────TPS63802
                     │
                     ▼
               3.3V_OUT
```

---

## 3.2 電源設計

USB入力は以下の順で接続する。

USB Type-C

↓

PTC

↓

IP5306

↓

DMG2305UX-13

↓

5V_BUS

↓

TPS63802

↓

3.3V_OUT

UPS切替はハードウェアで自動実行される。

---

## 3.3 USB Type-C

USB Type-C基板にはCC1・CC2用5.1kΩ終端抵抗が実装済みである。

外付けCC抵抗は使用しない。

USB GNDは5V_GNDへ接続する。

USB D+およびUSB D-は、**ヘッダーピンを経由して本体基板へ接続する**。

電源ラインとの長距離並走は避ける。

---

## 3.4 GND設計

本システムでは以下の3系統GNDを採用する。

| 系統 | 用途 |
|------|------|
| 5V_GND | 電源系 |
| 3.3V_GND | MCU・通信・センサー |
| SENSE_GND | ADC測定専用 |

電源基板上では3系統を独立して配線し、本体基板のXIAO ESP32S3 Plus近傍で一点接続する。

SENSE_GNDは測定専用であり、負荷電流のリターンとして使用してはならない。

---

## 3.5 10PINインターフェース

電源基板と本体基板は10PINヘッダーで接続する。

| 系統 | 信号 |
|------|------|
| 配電 | 5V_OUT ×2 |
| 配電 | 5V_GND ×2 |
| 配電 | 3.3V_OUT ×2 |
| 配電 | 3.3V_GND |
| 測定 | Battery_SENSE |
| 測定 | 5V_SENSE |
| 測定 | SENSE_GND |

配電系と測定系を混用してはならない。

# 4. I2C配線

## 4.1 基本方針

I2Cは3.3V系の共通通信バスとして使用する。

RTC、各種センサー、OLED操作基板、MCP23017を同一バスへ接続する。

通信品質を優先し、不要な分岐や長距離配線は避ける。

---

## 4.2 接続機器

| デバイス | I2Cアドレス | 備考 |
|-----------|------------|------|
| SCD41 | 0x62 | CO₂ |
| SGP41 | 0x59 | VOC / NOx |
| SPS30 | 0x69 | PM2.5 |
| LTR390 | 0x53 | UV / ALS |
| BME680 | 0x76 / 0x77 | 実装設定による |
| MCP23017 | 0x20 | GPIO拡張 |
| DS3231 | 0x68 | RTC |
| AT24C32 | 0x57 | EEPROM |
| OLED | 未確定 | 128×128 第一候補 |

---

## 4.3 配線ルール

- 電源は3.3V_OUTを使用する。
- GNDは3.3V_GNDを使用する。
- SDA・SCLは可能な限り並走させる。
- 高電流ラインとの長距離並走を避ける。
- 分岐は最小限とする。

---

## 4.4 プルアップ

I2Cプルアップは3.3V_OUTを基準とする。

プルアップ抵抗はバス全体で適切な値となるよう管理し、重複実装を避ける。

---

# 5. SPI配線

## 5.1 基本方針

SPIはE-PaperおよびmicroSDで共有する。

各デバイスはCS信号のみ独立させる。

---

## 5.2 接続構成

| 信号 | 接続先 |
|------|--------|
| SCK | E-Paper・microSD |
| MOSI | E-Paper・microSD |
| MISO | microSD |
| CS(E-Paper) | 個別配線 |
| CS(microSD) | 個別配線 |

OLEDはI2C接続のためSPIへ接続しない。

---

## 5.3 配線ルール

- SPI配線は可能な限り短くする。
- リターン経路は3.3V_GNDとする。
- CS信号は個別配線とする。
- 電源ラインと長距離並走させない。

---

# 6. I2S配線

## 6.1 基本方針

音環境観測にはICS-43434を採用する。

I2S専用バスとし、他の通信方式と共有しない。

---

## 6.2 GPIO割り当て

| GPIO | 信号 |
|------|------|
| GPIO39 | BCLK |
| GPIO40 | WS |
| GPIO41 | DATA |
| GPIO42 | 予備 |

---

## 6.3 接続

| 信号 | 接続先 |
|------|--------|
| BCLK | ICS-43434 |
| WS | ICS-43434 |
| DATA | ICS-43434 |
| VDD | 3.3V_OUT |
| GND | 3.3V_GND |
| L/R | GND固定 |

---

## 6.4 配線ルール

- BCLK・WS・DATAは並走配線とする。
- 5V_BUSおよびUSB通信線との長距離並走を避ける。
- 交差する場合は可能な限り直角交差とする。
- 配線長は3信号でできるだけ揃える。

---

# 7. USB通信配線

## 7.1 基本方針

USB Type-Cは以下の2用途を兼ねる。

- ESP32書込み・デバッグ
- USB給電

USB通信系は電源系から独立した配線とする。

---

## 7.2 配線構成

```text
USB Type-C
     │
     ├──── D+
     │
     └──────────────► ヘッダーピン
                          │
                          ▼
                  XIAO USB D+

USB Type-C
     │
     ├──── D-
     │
     └──────────────► ヘッダーピン
                          │
                          ▼
                  XIAO USB D-
```

---

## 7.3 配線ルール

USB D+・D-については以下を設計基準とする。

- ヘッダーピン経由で本体基板へ接続する。
- D+・D-は対として近接並走させる。
- 5V_BUSと長距離並走させない。
- TPS63802周辺を避ける。
- IP5306周辺を避ける。
- 必要時のみ直角交差とする。

---

## 7.4 USB GND

USB通信の基準GNDは5V_GNDを使用する。

USB通信専用GNDは設けない。

---

## 7.5 USB Type-C基板

USB Type-C基板は以下を正式仕様とする。

| 信号 | 接続先 |
|------|--------|
| VBUS | PTC入力 |
| GND | 5V_GND |
| CC1 | 基板内蔵5.1kΩ |
| D- | ヘッダーピン経由で本体基板 |
| D+ | ヘッダーピン経由で本体基板 |
| CC2 | 基板内蔵5.1kΩ |

CC1・CC2終端抵抗は基板に実装済みのため、外付け抵抗は使用しない。

# 8. D11～D19側面ランド配線

## 8.1 設計方針

XIAO ESP32S3 Plus の D11～D19 側面ランドは、本体基板上へ直接配線せず、専用取り出し基板を介して接続する。

取り出し基板は信号取り出し専用とし、アクティブ部品は実装しない。

---

## 8.2 構成

```text
XIAO ESP32S3 Plus
        │
 D11～D19側面ランド
        │
        ▼
専用取り出し基板
        │
        ▼
本体基板
```

---

## 8.3 設計ルール

- 信号取り出し専用とする。
- 保護回路は本体基板側へ配置する。
- 機械的応力を側面ランドへ加えない。
- メンテナンス時に交換可能とする。

---

## 8.4 配線ルール

- 電源線との長距離並走を避ける。
- JSTコネクタによる脱着を基本とする。
- 信号線は用途ごとに束ねる。
- 配線識別を容易にするためラベル管理を行う。

---

# 9. OLED操作基板

## 9.1 設計方針

OLED表示部とロータリーエンコーダは、本体基板から独立した専用基板へ実装する。

保守性向上および筐体設計自由度の確保を目的とする。

---

## 9.2 構成

OLED操作基板には以下を実装する。

| 部品 | 用途 |
|------|------|
| OLED | 保守画面表示 |
| Rotary Encoder | メニュー操作 |
| Push Switch | 決定操作 |

---

## 9.3 接続

```text
本体基板
      │
      ├────3.3V_OUT
      ├────3.3V_GND
      ├────SDA
      └────SCL
             │
             ▼
      OLED操作基板
```

Rotary Encoder の信号は MCP23017 を介して本体基板へ入力する。

---

## 9.4 配置

OLED操作基板は背面上部横梁へ固定する。

通常運転時には状態表示を行い、保守時のみ設定変更および診断画面を表示する。

---

## 9.5 設計ルール

- SPIは使用しない。
- I2C専用とする。
- 3.3V系で動作させる。
- コネクタ接続により交換可能とする。

---

# 10. 本体基板 ⇔ 電源基板インターフェース

## 10.1 設計方針

本体基板と電源基板は10PINヘッダーで接続する。

配電系と測定系を分離し、ノイズの影響を低減する。

---

## 10.2 インターフェース構成

```text
      電源基板
         │
         │
   10PIN Header
         │
         ▼
      本体基板
```

---

## 10.3 信号一覧

| 系統 | 信号 |
|------|------|
| 配電 | 5V_OUT ×2 |
| 配電 | 5V_GND ×2 |
| 配電 | 3.3V_OUT ×2 |
| 配電 | 3.3V_GND |
| 測定 | Battery_SENSE |
| 測定 | 5V_SENSE |
| 測定 | SENSE_GND |

---

## 10.4 配線ルール

### 配電系

- 太線を使用する。
- 配線長を最短とする。
- 電源ループを最小化する。

### 測定系

- 大電流を流さない。
- 配電線と束ねない。
- ADC入力まで専用配線とする。

---

## 10.5 GND設計

本体基板上で以下を一点接続する。

```text
5V_GND
      │
      ├──────┐
      │      │
3.3V_GND  SENSE_GND
      │
      ▼
System GND
(XIAO近傍)
```

電源基板上ではGNDを接続しない。

---
